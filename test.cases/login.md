# CT-001 — Login com credenciais válidas

**Sistema:** SauceDemo  
**Tipo:** Funcional  
**Prioridade:** Alta  

## Pré-condição
Usuário cadastrado: `standard_user` / `secret_sauce`

## Passos
1. Acessar https://www.saucedemo.com
2. Digitar usuário: standard_user
3. Digitar senha: secret_sauce
4. Clicar em Login

## Resultado esperado
Usuário redirecionado para a página de produtos

## Resultado obtido
✅ Conforme esperado
